# JaroMed & Diagnostic Center

A modern, responsive multi-page web application for **JaroMed & Diagnostic Center** located in Dasmariñas, Cavite. Built with clean HTML5, CSS3, and JavaScript, featuring local image optimization, SEO configurations, and a custom Light/Dark theme system with `localStorage` persistence.

## 📂 Project Structure

```text

├── assets/
│   └── images/          # Standardized WebP images & brand assets
